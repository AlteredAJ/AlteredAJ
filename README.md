### What I build

I turn hardware potential into reality. Currently shipping **[Universal DualSense Haptics](https://github.com/AlteredAJ/dualsense-haptics)** — a Windows desktop app that drives the DualSense controller's adaptive triggers, voice-coil rumble, and lightbar from real game telemetry at 60fps.

- **Rust + Tauri 2** — haptics engine, HID output, telemetry parsers
- **DSP** — low-pass, EWMA envelopes, Pacejka tire models, slip crossover
- **UDP telemetry** — Forza Data Out, F1 23, Assetto Corsa
- **TCP bridges** — Minecraft Fabric mod, custom JSON protocol
- **License infra** — Cloudflare Workers, Gumroad API, beta key minting
- **UI** — vanilla HTML/CSS/JS, glass-morphism design system, Manrope type
